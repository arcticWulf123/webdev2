# Student Directory
 
**Description:** This program can create, read, update and delete entries inside the student database system using Spring Boot and HTML.
 
## Requirements
 
    REQ 1: The user can view the list of students.
    REQ 2: The user can create a new student.
    REQ 3: The user can update a student's information.
    REQ 4: The user can delete a student from the database.
