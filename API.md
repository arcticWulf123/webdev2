# Department API — Documentation

REST API for managing departments, built with Spring Boot 4 (Java 26) and MySQL.

- **Base URL:** `http://localhost:8080`
- **Content type:** `application/json`
- **CORS:** `http://localhost:3000` is allowed for all `/api/**` routes, with credentials.

## Data model

`DepartmentDTO` (all responses that return a department use this shape):

| Field | Type | Notes |
|---|---|---|
| `id` | number | Generated by the database |
| `name` | string | Department name |

---

## Error responses

Every error uses the same body (`ErrorResponse`):

| Field | Type | Notes |
|---|---|---|
| `status` | number | HTTP status code |
| `message` | string | Human-readable summary |
| `timestamp` | string | ISO-8601 instant, e.g. `2026-11-18T11:03:27.961865800Z` |
| `errors` | array or `null` | Only populated for validation errors; each item has `field` and `message` |

```json
{
  "status": 400,
  "message": "Validation failed",
  "errors": [
    { "field": "name", "message": "Name cannot be blank" }
  ],
  "timestamp": "2026-11-18T11:03:27.961865800Z"
}
```

| Status | When |
|---|---|
| `400 Bad Request` | Body fails validation, or the JSON body is malformed |
| `404 Not Found` | The requested department id does not exist |
| `409 Conflict` | The department name is already taken |
| `500 Internal Server Error` | Any unexpected failure (details are only in the server log) |

---

## GET `/api/departments`

Returns a paginated list of departments. Optionally filters by name.

**Query parameters**

| Name | Type | Default | Description |
|---|---|---|---|
| `page` | number | `0` | Zero-based page number |
| `size` | number | `20` | Page size, capped at `100` |
| `sort` | string | `id` | Sort field: `id` or `name`. Also accepts `name,desc` syntax |
| `direction` | string | `asc` | `asc` or `desc` (ignored when `sort` includes a direction) |
| `name` | string | *(none)* | Case-insensitive partial match on the name |

**Response `200 OK`**

```json
{
  "content": [
    { "id": 1, "name": "IT" },
    { "id": 2, "name": "Sales" }
  ],
  "pageable": { "offset": 0, "pageNumber": 0, "pageSize": 20, "paged": true, "unpaged": false },
  "number": 0,
  "size": 20,
  "numberOfElements": 2,
  "totalElements": 2,
  "totalPages": 1,
  "first": true,
  "last": true,
  "empty": false
}
```

**Examples**

```bash
curl.exe "http://localhost:8080/api/departments?page=0&size=5&sort=name,asc"
curl.exe "http://localhost:8080/api/departments?name=IT"
curl.exe "http://localhost:8080/api/departments?size=999"
```

`?size=999` is capped: the response metadata reports `"size": 100`.

**Status codes:** `200`, `500` (unexpected error)

## GET `/api/departments/{id}`

Returns one department by id.

**Path parameters**

| Name | Type | Description |
|---|---|---|
| `id` | number | Department id |

**Response `200 OK`**

```json
{ "id": 1, "name": "IT" }
```

**Response `404 Not Found`**

```json
{
  "status": 404,
  "message": "Department not found with id: 99999",
  "errors": null,
  "timestamp": "2026-11-18T11:02:00.337398300Z"
}
```

**Example**

```bash
curl.exe "http://localhost:8080/api/departments/1"
```

**Status codes:** `200`, `404`, `500`

## POST `/api/departments`

Creates a department.

**Request body** (`CreateDepartmentRequest`)

| Field | Type | Required | Validation |
|---|---|---|---|
| `name` | string | yes | `@NotBlank`, `@Size(max = 50)` |

```json
{ "name": "Sales" }
```

**Response `201 Created`**

Header: `Location: http://localhost:8080/api/departments/6`

```json
{ "id": 6, "name": "Sales" }
```

**Response `400 Bad Request`** — missing or invalid body

```json
{
  "status": 400,
  "message": "Validation failed",
  "errors": [
    { "field": "name", "message": "Name cannot be blank" }
  ],
  "timestamp": "2026-11-18T11:03:27.961865800Z"
}
```

A name longer than 50 characters returns field message `Your name cannot exceed more than 50 characters`.
Malformed JSON returns `{ "status": 400, "message": "Malformed JSON request body", ... }`.

**Response `409 Conflict`**

```json
{
  "status": 409,
  "message": "Department name already exists: Sales",
  "errors": null,
  "timestamp": "2026-11-18T13:37:08.570694300Z"
}
```

**Example**

```bash
curl.exe -X POST http://localhost:8080/api/departments -H "Content-Type: application/json" --data-raw "{\"name\":\"Sales\"}"
```

**Status codes:** `201`, `400`, `409`, `500`

## PUT `/api/departments/{id}`

Replaces a department's name.

**Path parameters:** `id` (number, required)

**Request body** (`UpdateDepartmentRequest`)

| Field | Type | Required | Validation |
|---|---|---|---|
| `name` | string | yes | `@NotBlank`, `@Size(max = 50)` |

```json
{ "name": "IT Support" }
```

**Response `200 OK`**

```json
{ "id": 1, "name": "IT Support" }
```

**Response `404 Not Found`** — no department with that id (same shape as `GET` 404).

**Response `409 Conflict`** — the new name belongs to a different department.

**Response `400 Bad Request`** — missing or invalid `name`.

**Example**

```bash
curl.exe -X PUT http://localhost:8080/api/departments/1 -H "Content-Type: application/json" --data-raw "{\"name\":\"IT Support\"}"
```

**Status codes:** `200`, `400`, `404`, `409`, `500`

---

**Path parameters:** `id` (number, required)

**Request body**

| Field | Type | Required | Validation |
|---|---|---|---|
| `name` | string | yes | `@NotBlank`, `@Size(max = 50)` |

**Response `200 OK`**

```json
{ "id": 1, "name": "IT Support" }
```

**Status codes:** `200`, `400`, `404`, `409`, `500`

---

## DELETE `/api/departments/{id}`

Deletes a department.

**Path parameters:** `id` (number, required)

**Response `204 No Content`** — empty body.

**Response `404 Not Found`**

```json
{
  "status": 404,
  "message": "Department not found with id: 99999",
  "errors": null,
  "timestamp": "2026-11-18T11:02:00.337398300Z"
}
```

**Example**

```bash
curl.exe -X DELETE http://localhost:8080/api/departments/6
```

**Status codes:** `204`, `404`, `500`

---

## Status code summary

| Code | Meaning |
|---|---|
| `200 OK` | Successful read/update |
| `201 Created` | Department created (includes `Location` header) |
| `204 No Content` | Department deleted |
| `400 Bad Request` | Validation failure or malformed JSON |
| `404 Not Found` | Unknown department id |
| `409 Conflict` | Duplicate department name |
| `500 Internal Server Error` | Unexpected error; safe message only |

## Running the automated tests

The Postman collection is committed as `api_tests.json` at the repository root:

1. Start the app on port 8080.
2. In Postman: **Import** → `api_tests.json` → **Run collection**.
3. Or from a terminal (requires Node): `npx newman run api_tests.json`.

The collection creates its own department and deletes it again, so it can be run repeatedly.
